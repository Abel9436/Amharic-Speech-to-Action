
# Goalmate App 🚀

A beautiful and lightweight Flutter onboarding experience designed for the Nexacore Technologies technical assessment. This app demonstrates a smooth welcome flow, user personalization, and interactive animations using **Rive**.

---

## ✨ Features

### 🌟 Screen 1: Animated Welcome Page
- Fullscreen layout with engaging **Rive character animation**
- Friendly welcome message: _“Ready to begin your journey?”_
- A clean and modern **"Get Started"** button with animated screen transition

### 🧩 Screen 2: User Profile & Interest Setup
- Input fields for:
  - Name
  - Goal (e.g., “Lose weight”, “Find love”, “Learn to code”)
- Selectable interests via **interactive chips**
- **Rive character responds dynamically** based on user input
- Submit button sends goal to a **mock API** and transitions to the next screen

### 🌈 Screen 3 (Bonus): Personalized Welcome
- Displays a tailored message based on user input
- Example: _“Welcome, Alex! Let’s help you learn to code.”_

---

## 🛠️ Tech Stack

- **Flutter** + **Dart**
- **Rive** for real-time interactive animations
- **BLoC** for robust state management
- **Responsive UI** with light/dark mode toggle
- **Custom themes** with green as the primary color
- **Smooth transitions** and clean animations

```
├── widgets/            # Reusable widgets

```



## 📦 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/Abel9436/goalmate.git
   cd Goalmate
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
