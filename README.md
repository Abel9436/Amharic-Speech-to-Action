# Amharic Speech-to-Action

Fine-tuning and evaluating ASR for Amharic, plus a thin LLM agent that turns a spoken Amharic request into a structured tool call. The main question is **how ASR errors carry through into wrong agent actions**. Every number in this README is generated by a script in this repo and filled in from `results/`.

> Status: Phase 1 (foundations and zero-shot baseline). Later phases cover the data pipeline, LoRA fine-tuning, the recorded eval set, the agent layer, end-to-end error propagation, a demo and the write-up.

## Zero-shot baseline: FLEURS `am_et` test

"Raw" WER uses light cleanup only (punctuation, case, whitespace). "Norm" WER also collapses homophone letter families (ሀ/ሐ/ኀ, ሰ/ሠ, አ/ዐ, ጸ/ፀ) and converts Ge'ez numerals to digits (`src/normalize.py`). CIs are 95% percentile bootstrap intervals over utterances.

## Quickstart

```bash
pip install -r requirements.txt
make test
make baseline && make errors && make tables   # needs a GPU (Kaggle/Colab T4)
```

## Reproduce

| target | what it does | output |
|---|---|---|
| `make test` | unit tests (normalizer, numerals, metrics, error buckets) | — |
| `make lint` | `ruff` | — |
| `make baseline` | zero-shot Whisper/MMS on FLEURS (`configs/baseline.yaml`) | `results/baseline.csv`, `results/baseline/*.csv` |
| `make errors` | error-bucket analysis of the per-utterance results | `results/baseline_errors.md`, `.json` |
| `make tables` | rewrite README tables from `results/` | `README.md` |

Run a single model or a quick subset:

```bash
python -m src.baseline --model openai/whisper-small --max-samples 50
```

## Layout

```
configs/      YAML configs per stage
src/          normalize.py, numbers.py, baseline.py, transcribe.py, eval/, agent/
tests/        pytest suite for all pure-Python logic
results/      every reported metric (CSV/JSON) and figures/
notebooks/    thin Kaggle/Colab wrappers around src/
```

## Data and models

- FLEURS: Conneau et al., 2022, *FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech* (`google/fleurs`, config `am_et`, CC-BY-4.0).
- Whisper: Radford et al., 2022 (`openai/whisper-*`).
- MMS: Pratap et al., 2023 (`facebook/mms-1b-all`, `amh` adapter).
